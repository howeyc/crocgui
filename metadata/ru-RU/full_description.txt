croc это инструмент для простой и безопасной передачи файлов между любыми двумя компьютерами.

<b>Основные возможности</b>
- поддержка передачи данных между <b>любыми двумя компьютерами</b> (через ретранслятор)
- поддерживает <b>сквозное шифрование</b> (на базе протокола PAKE)
- позоляет <b>кросс-платформенную</b> передачу (Windows, Linux, macOS)
- передача и приём <b>нескольких файлов и каталогов</b> одновременно
- не требует настройки <b>локального сервера</b> или проброса портов
- приоритетная работа через <b>IPv6</b> с автоматическим переходом на IPv4

Консольная версия приложения, использующая ту же библиотеку что и этот интерфейс, доступна здесь:
https://github.com/schollz/croc

<b>Этот интерфейс позволяет</b>
- использовать одноразовые пароли с секретом из поля или из переменной среды запуска CROC_SECRET
- для Windows, Linux, macOS помимо диалогов выбора файлов или каталогов использовать драг-энд-дроп, командную строку
- для Android помимо диалогов выбора файлов или каталогов использовать меню файловых менеджеров "Поделится" одним или несколькими файлами или "Открыть с помощью"
- для Android передача без вложенных каталогов а приём даже вложенных с сохранением их в .zip файлы
- видеть протокол в цвете пусть и не так быстро как в консоле
- для Android видеть протокол через `adb logcat -s croc`

<b>Как по мне</b>
Цифровая подпись издателя — это механизм, применяемый централизованными платформами (магазинами приложений) для модерации и валидации контента.
Для прямого распространения "из первых рук" (например, через GitHub) криптографического хеша, предоставленного автором, достаточно для верификации целостности и происхождения файла.
Подпись третьей стороны, в свою очередь, служит признаком проверки платформой и демонстрирует соответствие её правилам, политикам безопасности или техническим требованиям.
